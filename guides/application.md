# 从设计稿到成品

以下是原创转译的起稿建议。字号和比例随用户的模板、屏幕、观看距离及真实文案调整。原作观察另见[原作对照](visual-evidence.md)。

## 网站与应用

- **阅读与列表。** 从已有品牌或系统中文字体起稿；没有现成字体时可用思源黑体或苹方。正文可从 16–18 CSS px、1.5–1.7 倍行高试排。用长标题和真实列表数据决定列宽。宽屏用同一条轴对齐标题、筛选与首列，小屏让日期、作者等次要字段回到对应条目。共用页眉里的三色标记可以缩短，仍须看得清三段。
- **操作与状态。** 象牙白底上的小字用炭黑。信号橙底配炭黑字的对比度约 5.37∶1；橙字放在象牙白底上约 2.71∶1，小号按钮、链接或图注容易读不清。选中项可以用一条深色短线配合字重，键盘焦点用有对比的轮廓。保留错误、成功和数据类别的既有含义。三色组合放在栏题或模块边缘，避免读者把它看成三个可选状态。
- **检验。** 在实际桌面宽度和窄屏各看一遍长标题、选中项与同屏相邻条目。若所有内容挤成相同的圆角卡片，先把需要横向比较的字段并成一张表或一组行，让分区线和标题承担层级。

## PPT 与报告

- **决定一页承担什么。** 开篇让标题和一个主体建立方向；证据页给图表或引文最多空间；结论页放大一个真实结果。沿用标题起线、图注基线或三色落点，使翻页前后有连续性。明暗转换适合论证发生转折的位置。
- **从观看距离倒推字号。** 常规 16∶9 投影稿可先试 30–40 pt 中文页题、20–26 pt 正文；长题先按语义换行。需要逐列精读的大表可拆成概览与细表。打印报告允许更密的说明，把单位靠近数值，把来源放在对应图下。使用真实的小数、百分号和长单位检查数字列，窄体大数字更适合孤立的关键值。
- **把图形放进母版。** 用一组三个相邻色块作页脚、标题下划线或侧边标记，在分节页放大或延长其中一种组合。数据图有自己的图例。可在幻灯片浏览视图查看连续三页，再打开实际导出页，检查折行、缺字、细线和三色是否仍可分辨。

## 海报与图像占主导的版面

用主体轮廓或图片中的透视决定走势，将标题放在能被这条走势接住的空白区。项目已有照片时，可在繁杂背景与标题之间加一小块实底。需要印刷感时，可取裁出画框的同心细线或由密到疏的网点，在标题背后或大色块边缘出现一次。保持正文与图表底部安静。[主宣图](https://web.hycdn.cn/upload/image/20240514/d8f007f67d7e91f6c72d0ffdddcbb327.jpg) · [专项调查横幅](https://ak.hycdn.cn/announce/images/20230422/9a1bbb622fde3d9e8d352758868a8e4d.png)

## 辨识度不足时怎样改

| 成品症状 | 优先调整 |
| --- | --- |
| 只在封面看得出孤星，进入正文就像另一套作品 | 把完整三色移到共用页眉、页脚或侧栏；内页缩小占比，在实际阅读尺寸保留三个清晰色段。 |
| 三色已经齐了，页面仍像普通模板贴了色条 | 把色带接到一个真实栏题上，与字面等高或共用端点。再从用户内容中选定一个尺度关系，例如突出一项核心数据，或把主照片扩到一栏以外。 |
| 每一页都有大尾流，正文字图开始退居其次 | 数据页把尾流收成栏边细带，释放证据区；封面保留原本的大走势。 |
| 画面只剩深色面板、伪终端字样和橙色发光线 | 拿掉无对应内容的小字，恢复暖白或炭黑的大面。把细节集中到可用的控件、材料边缘或值得近读的说明处。 |
