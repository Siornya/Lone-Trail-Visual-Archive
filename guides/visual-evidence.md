# 原作对照

这是一份选读的美术学习笔记。左栏提出形式问题，右栏定位原作怎样解决它。把同一问题换成用户项目里的真实对象，再判断哪种手法值得借用。

| 想解决的问题 | 看哪里、如何使用 |
| --- | --- |
| 三种颜色怎样跨版面保持识别？ | 主宣图的英文标题左侧是上青、中黄、下红的三条矩形。四周年横幅左上把圆角文字标签接到青黄红分段，底部又把它们压成细线；先导 PV 封面在字标下方以红黄青反向排列。补给箱上的三色并行线还沿壳体前缘折下。使用尾流状弯带时，可从这种并行、转向和连续性出发。 [孤星主宣图](https://web.hycdn.cn/upload/image/20240514/d8f007f67d7e91f6c72d0ffdddcbb327.jpg) · [四周年横幅](https://ak.hycdn.cn/announce/images/20230421/7905693bf64051121edb0ff4cfe77fd0.png) · [先导 PV](https://www.bilibili.com/video/BV12m4y12726/) · [专项调查](https://ak.hycdn.cn/announce/images/20230422/9a1bbb622fde3d9e8d352758868a8e4d.png) |
| 上下方向有没有可直接比对的色带？ | AA2 国服资源中，莱茵调查收益界面的 up 装饰贴图与确认界面的 down 装饰贴图都是 15 × 15。按原图从上到下读，前者为红、黄、青，后者为青、黄、红。两张来自不同界面，最终位置和缩放需对照实机。 [up 贴图](https://raw.githubusercontent.com/ArknightsAssets/ArknightsAssets2/cn/assets/dyn/ui/%5Buc%5Drhine/research/dailyharvest_state/dec_color_sheet_up.png) · [down 贴图](https://raw.githubusercontent.com/ArknightsAssets/ArknightsAssets2/cn/assets/dyn/ui/%5Buc%5Drhine/state/confirm_state/dec_color_sheet_down.png) |
| 三色会落在一整页的哪里？ | 国服两版大厅在底部 LONETRAIL 字标下沿都保留红、黄、青三段。综合调查数据库总览把三段转成左栏下端的竖线；专项调查的完成提示把三条细带叠在浅色面板底边。可借用这种尺度变化，让封面和密集内页共享一组颜色。[大厅差分](https://prts.wiki/w/孤星#活动大厅差分) · [专项调查录屏](https://www.bilibili.com/video/BV1Co4y1F7gf/?p=2) · [数据库总览与影像报告](https://www.bilibili.com/video/BV1Co4y1F7gf/?p=3) |
| 一张舱室图怎样同时表现理想与工程？ | 主宣图中，白色弧面沿通道后退，失重人物身边有扶手。画面前方的色条、字标与同心圆是平面层。画原创海报时，可让人物动作呼应设施，让平面层承担活动识别。[鹰角主宣图](https://web.hycdn.cn/upload/image/20240514/d8f007f67d7e91f6c72d0ffdddcbb327.jpg) |
| 明亮研究空间怎样过渡到孤独深空？ | 比较两张无菜单背景的空间深度与亮部面积，再看同一界面怎样叠在背景上。可用这一变化组织同一套作品的开篇与收束。[交错螺旋](https://media.prts.wiki/7/74/Avg_38_ex05.png) · [孤星](https://media.prts.wiki/f/fa/Avg_38_ex06.png) · [游戏大厅差分](https://prts.wiki/w/孤星#活动大厅差分) |
| 复古设备怎样让人相信它有用途？ | 「专项调查」图中的补给箱有嵌入的显示窗、扣件、提手、格栅和窄色带。设计另一种设备时，先重新安排其操作部位，再考虑沿用壳体和印刷语言。外观能支持对结构的观察，内部机构需另有依据。[鹰角专项调查公告图](https://ak.hycdn.cn/announce/images/20230422/9a1bbb622fde3d9e8d352758868a8e4d.png) |
| 大场景怎样避免都画成一条圆形走廊？ | 能量井以纵向层叠组织尺度，聚焦发生器以倾斜环体强调方向，万星园让星象仪成为观察中心，静滞所以反复的矩形体建立深度。按场所的作用选一种几何秩序。[综合调查数据库·影像报告](https://prts.wiki/w/孤星/综合调查数据库#影像报告) |
| 如何呈现统一性和人的温度？ | 工程科设计的「枝丫」文件架是公司常见物，缪尔赛思亲种的草坡和亲手雕的长凳却只属于这个使用者。做人物访谈集时也可沿用这个关系：全书用同一套版心与标题，每位受访者的照片和手迹保留自己的质地。[游戏家具·莱茵科技生态园](https://prts.wiki/w/莱茵科技生态园) |

**术语出处。** 《星空》主美 Istvan Pely 用 NASA-Punk 描述从当代航天技术向未来推演、让虚构设备可信的做法。本指南借这个词分析《孤星》的工程细节。[Xbox Wire 开发者访谈](https://news.xbox.com/en-us/2022/02/17/exclusive-signed-starfield-art-giveaway/)
